{%- comment -%} Renders the organizers' contact address. While `contact_email` in _data/workshop.yml is still the literal ``, this prints it as escaped plain text — no mailto link, so the site never ships a working link to an address that does not exist. Put a real address in that field and every occurrence on the site turns into a mailto link on its own. The switch is "does the value contain an @". {%- endcomment -%} {%- assign addr = site.data.workshop.contact_email -%} {%- if addr contains "@" -%} {{ addr }} {%- else -%} {{ addr | escape }} {%- endif -%}
